Currently trying (and struggling) to work my way through Jech's Set Theory

Theorem I like right now:

A filter is an ultrafilter iff it is maximal.

(\(\Longrightarrow\)) Assume \(F\) is an ultrafilter on \(S\) and \(F\subsetneq F'\).
Let \(X\not\in F\) and \(X \in F'\). \(S-X \in F \implies S-X \in F'\), but \(X\in F'\), contradiction.

(\(\Longleftarrow\)) Assume \(F\) is maximal but not an ultrafilter.
Let \(X \not\in F\) and \(S-X \not\in F\), consider \(F \cup \{X\}\). This set has the finite intersection property, otherwise there exists a \(Y\in F\), \(Y \cap X = \emptyset\),
which would mean that \(Y \subset S-X \implies S-X\in F\). Contradiction.
Therefore \(F\cup\{X\}\) can be extended to a filter on \(S\) which contains \(X\) whilst \(F\) doesn't. Contradiction.
